# 가위바위보 만들기 (엔트리 수업 슬라이드)

초등학생 SW영재 수업용 슬라이드예요. 엔트리로 가위바위보 게임을 만들고, 내 습관을 배우는 컴퓨터로 바꾸는 과정을 단계별로 설명해요.

| 차시 | 내용 | 슬라이드 |
|---|---|---|
| 1차시 | 랜덤 가위바위보 만들기 (19장) | https://liebe842.github.io/rps-slides/ |
| 2차시 | 예측 가위바위보 만들기 (37장) | https://liebe842.github.io/rps-slides/day2/ |

- **조작키:** ←/→ 또는 클릭으로 넘기기 · `N` 선생님 메모 · `F` 전체 화면
- **슬라이드 번호로 바로 가기:** 주소 끝에 `#16`처럼 번호를 붙여요
- **지난 시간 완성본 파일 (2차시 시작 파일):** https://liebe842.github.io/rps-slides/day2/start.ent

## 1차시 구성

1. 오늘 만들 게임과 숫자 약속 (1 가위 · 2 바위 · 3 보)
2. 준비물과 전체 흐름
3. 엔트리에서 차례대로 만들기
4. 승패 판정의 비밀 (나 − 컴퓨터)
5. 점수판, 테스트, 도전 과제
6. 더 생각해 보기: 승률, 연승 콤보, 3판 2선승

## 2차시 구성

1. 오늘 배울 것, 수업 전 점검, 지난 시간 완성 코드와 파일 받기
2. 사람의 습관과 컴퓨터의 예측
3. 습관표 읽고 채우기
4. 표를 9칸 리스트로 펴고 칸번호 찾기
5. 1단계: 내 손을 습관표에 기록하기
6. 2단계: 가장 큰 칸을 찾아 다음 손 예측하기
7. 3단계: 예측한 손을 이기는 손 내기
8. 실험하고 정리하기

게임은 [entry-vibe-coding](https://github.com/205sla/entry-vibe-coding) 환경으로 만들었어요. 그림은 Codex로 생성했어요.
